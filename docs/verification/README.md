# Execution Evidence (S0.2.5 / Article XVII / ARCH-052)

This directory holds the machine-generated execution evidence manifest.

## Files

- `latest-execution.json` — the manifest for the most recent gate run at the
  current HEAD. **Gitignored** — it's a generated artifact, not a tracked
  source file. Generated by `scripts/generate-execution-evidence.sh`. In CI,
  it's uploaded as a GitHub Actions artifact named `execution-evidence-<sha>`
  with 30-day retention.
- `history/` — archived manifests from previous runs. Also gitignored.

## Why the manifest is gitignored

The verifier (`scripts/verify-execution-evidence.sh`) requires
`manifest.commit_sha == git rev-parse HEAD`. If the manifest were committed
as a tracked file, the act of committing it would advance HEAD by 1 commit,
making `manifest.commit_sha` describe the PREVIOUS commit (not the manifest
commit). Strict equality would fail.

So the manifest is a GENERATED artifact, not a tracked source file. The
directory itself is tracked (via this README) so the structure exists in the
repo. The manifest files are gitignored and produced by:

1. **Locally**: `bash scripts/generate-execution-evidence.sh <milestone>`
2. **In CI**: the `execution-evidence` GitHub Actions job runs the generator
   and uploads the manifest as an artifact.

## Manifest format

```json
{
  "milestone": "S0.2.5",
  "commit_sha": "<full SHA>",
  "repository": "https://github.com/pectoraux/universal-comm-os",
  "branch": "main",
  "timestamp": "2026-08-20T18:00:00+00:00",
  "environment": {
    "os": "Linux x86_64",
    "node": "v20.10.0",
    "package_manager": "bun 1.1.x",
    "runtime": "vitest 4.1.x"
  },
  "commands": [
    {
      "label": "typecheck",
      "command": "npx tsc --noEmit",
      "exit_code": 0,
      "duration_ms": 1234,
      "summary": "PASS"
    },
    ...
  ],
  "results": {
    "tests": "344 passed / 0 failed",
    "architecture": "291 passed / 0 failed",
    "security": "11 passed / 0 failed",
    "typecheck": "PASS"
  },
  "overall_status": "VALID"
}
```

## How to generate + verify

```bash
# Generate (must be at a clean HEAD):
bash scripts/generate-execution-evidence.sh S0.2.5

# Verify:
bash scripts/verify-execution-evidence.sh
```
